# Code Availability and Method Summary

The tumor metabolism knowledge-base and evidence-grounded explanation workflow is available at https://github.com/chenms2000/meta_down_analysis and archived as GitHub release `v1.0.0-paper`. The workflow links input metabolites or precomputed differential trait-score records to normalized metabolite entities, compound-matching evidence, knowledge-graph relationships, literature evidence, ranking outputs, and confidence tiers. It supports metabolite matching, graph projection, literature-evidence integration, differential-table analysis, confidence-tier assignment, and auditable explanation generation. Ambiguous matches, ratio traits, weak graph propagation, and model-only rankings are retained as lower-confidence or appendix-level signals rather than primary conclusions. External language models, when enabled, are used only as read-only narrative generators over frozen analysis packages and cannot create entities or alter scores. Code and documentation are released under the MIT License; third-party databases, literature-derived resources, and downloaded or rebuilt data remain subject to their original licenses and citation requirements.
