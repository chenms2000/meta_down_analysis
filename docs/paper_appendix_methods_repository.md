# Code Availability

The tumor metabolism knowledge-base and evidence-grounded explanation workflow is available at https://github.com/chenms2000/meta_down_analysis and archived as GitHub release `v1.0.0-paper`. The repository includes metabolite matching, graph projection, literature-evidence integration, differential-table analysis, confidence-tier assignment, and auditable explanation scripts. Code and documentation are released under the MIT License; third-party databases and literature-derived resources remain subject to their original licenses and citation requirements.
