输入与流程

默认使用本地确定性解释器；外部 LLM 只负责改写叙述，不能改图谱或评分。

1. 准备数据CSV/TSV、JSON 或自然语言列表
2. 补充背景结构化必填 context
3. 运行分析规范化、图传播、证据回链
4. 查看结果先看质量，再看解释和排名
详细说明

推荐列名：name、metabolite、HMDB、ChEBI、PubChem CID、KEGG、InChIKey、formula、mz、adduct、log2FC、pvalue、padj、direction。

匹配规则会把不确定项放进复核队列，不会强行进入评分。结果里的“证据可追溯”表示排名项至少能回链到图谱边、文献证据或来源记录。

上传正式 CSV 时需要填写结构化背景字段。软匹配会加权相关背景，硬匹配只保留明确命中的背景条目。

数据输入 上传文件或直接粘贴表格
备注：差异表可包含 metabolite,log2FC,pvalue,padj,direction；也可以使用 HMDB、ChEBI、KEGG、InChIKey 等 ID 列。脏数据或重复项会进入复核队列。
研究问题与背景 结构化背景必填
示例问题：解释主要通路和方向性；指出需要复核的输入；整理成组会汇报摘要；列出优先验证的通路、靶点和证据依据。
这些字段会组成结构化 context：cancer_type、tissue、cell_type、comparison、analysis_goal。它们只影响贴合度重排和解释边界，不会写入图谱事实。
分析参数 控制解释后端、图搜索深度和证据回查数量
